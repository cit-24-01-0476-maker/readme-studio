# Community sources and dependencies

The catalog contains 628 unique sourced entries, plus six original guided starters, for 634 gallery entries. It is a snapshot, not a claim that every upstream profile remains available.

- [Furkan Beydemir — Awesome GitHub Profile](https://github.com/beydemirfurkan/awesome-github-profile): 32 design-led templates, source SVGs, sample Markdown and setup guides. MIT. Full license is included in `dist/licenses/design-led-MIT.txt` and every exported design bundle.
- [Abhishek Naidu — Awesome GitHub Profile README](https://github.com/abhisheknaiidu/awesome-github-profile-readme): category and profile-link index. The index is CC0-1.0, with license included in `dist/licenses/profile-index-CC0.txt`. This does not relicense the linked developers' individual READMEs.
- [Durgesh Samariya — Awesome GitHub Profile README Templates](https://github.com/durgeshsamariya/awesome-github-profile-readme-templates): links to community README examples. Those READMEs are fetched only when previewed or opened; no blanket reuse license is asserted. Original source and attribution are shown on each entry.

Community entries are deduplicated by case-insensitive username; entries in both indexes keep their original categories and archive fallback URL. Every entry has a source link. Upstream profile availability and remote images can change. The gallery remains browsable offline after loading; community source previews require network access unless already cached during that session.

Pinned browser libraries downloaded from their official npm distributions via jsDelivr:

- [marked 18.1.1](https://www.npmjs.com/package/marked/v/18.1.1) — MIT. GitHub-flavored Markdown parsing.
- [DOMPurify 3.4.17](https://www.npmjs.com/package/dompurify/v/3.4.17) — Apache-2.0 OR MPL-2.0. HTML sanitization.
- [JSZip 3.10.1](https://www.npmjs.com/package/jszip/v/3.10.1) — MIT OR GPL-3.0-or-later. In-browser ZIP export.

Their distribution headers retain upstream copyright and license notices. SVGs are loaded as images, never injected as executable inline markup. Community HTML is sanitized before insertion; scripts, embedded frames, event handlers, unsafe links, forms, inline styles, and clobbering identifiers are stripped.
